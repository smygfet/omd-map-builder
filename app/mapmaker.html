    Mission
    Heroes only: orcs can't use it. It joins the floors at its ends (keep floor there on side A).

    VS rules
    Prices in coins: F1 5 light orcs, F2 8 kobold runners (top row); F3 2 heavy orcs, F4 1 ogre; F5 1 unstable rift (it opens on the other side and lets out enemies until it is destroyed); F6 a random curse on the other side: coins stolen 1 min, traps off 1 min, double life, no money, fragile rift (double cost), armoured orcs (all for a wave), sends cost double 2 min, or heavy boots 1 min. One curse at a time per side.

    Starting coins per player and rift points per side. Leave empty for the mission's own.

    Style

    Heights count from the floor beside the wall or under the ceiling, so they climb with hills and ramps.

    The map's floor style is the default. Paint other floors on single areas with the Floor style tool (P). The builder lays Deathtrap's own kit pieces on your grid.

    Stamps

    Click a stamp, then click the map to place it. R turns it, H flips it, Esc stops. Copy your own pieces with the Select tool (S) and Ctrl+C / Ctrl+V.

    Map tools

    Map size

    Each cell is one kit unit: 3 × 3 m, which is 2 × 2 trap tiles. Up to 80 × 80 cells (240 m). Big maps take longer to build and run heavier in game.

    Save map

    1. Click Save map file. With changes since the last save, the version goes up by one. It goes to your Downloads folder as map.omdmap.json (or straight into OMD Map Builder when the app opened this page).
    2. OMD Map Builder picks up new .omdmap.json files from Downloads. Press Build & install there.
    3. Start the game: the map is its own mission in the run's mission choice.

    Map file text

    To load a map from text, paste it here and click Load this map.

    Share map

    The share file is map.omdshare.json. OMD Map Builder doesn't pick it up by itself, so it never lands in your own build twice. The share code is the same map as text, for chat. Your friend opens either one here with Open file… or the box below, then can edit, save and build it.

    Open a shared map

    Paste a share code (or map file text). It replaces the current map; Undo brings it back.

    VS games: the map has to be built into the game on both PCs. After you build, send the friend pack as well.

    Generate a map

    Rooms joined by corridors, walled in, with the rift in a corner room and every orc spawn at least 80 % of the map's length away from it. Every route is checked. It replaces the current map; Undo brings it back.
